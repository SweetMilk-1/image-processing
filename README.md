# Лабораторная работа 1. Цифровая фильтрация изображений

Состав работы:

- `lab1.cpp` — консольное приложение (C++/OpenCV), программная часть.
- `build.sh` — сборка программы.
- `test_image.tiff` — исходное полутоновое изображение (USC-SIPI 5.1.11, открытая база).
- `results/` — результирующие изображения (исходное, фильтры табл. 1.1, контуры, монтаж).
- `report.md` / `Отчет.docx` — краткий отчёт по плану 1.8.
- `gen_images.py` — генератор изображений (Python-порт алгоритмов из `lab1.cpp`).

## Сборка и запуск (C++)

OpenCV ставится через Homebrew: `brew install opencv` (на этой машине установлена
версия 5.0.0). `build.sh` сам определяет каталог заголовков (opencv4 или opencv5).

```bash
./build.sh
./lab1 test_image.tiff results --variant 1            # только сохранение
./lab1 test_image.tiff results --variant 1 --show      # + вывод на экран (окна)
```

Альтернативная сборка через pkg-config (если настроен):
```bash
g++ -std=c++17 -O2 lab1.cpp -o lab1 $(pkg-config --cflags --libs opencv4)
```

Параметры:
- 1-й аргумент — путь к изображению;
- 2-й (необяз.) — каталог результатов (по умолчанию `results`);
- `--variant N` — вариант из табл. 1.2 (1..10), по умолчанию 1;
- `--show` — показать окно с монтажом и исходным изображением.

## Что реализовано

Таблица 1.1 (своя свёртка, без `cv::GaussianBlur`/`cv::filter2D`):
1. фильтр Гаусса 3×3 — маска `{1,4,1;4,16,4;1,4,1}`, k=36;
2. фильтр Гаусса 5×5 — внешнее произведение `[1,4,6,4,1]`, k=256;
3. фильтр «Мозаика» 3×3 — неперекрывающиеся блоки, среднее по блоку;
4. фильтр апертурной коррекции 3×3 — маска `[[-1,-1,-1],[-1,13,-1],[-1,-1,-1]]`,
   X = 100/S + 8 (S = 20 % → X = 13), нормировка k = X − 8 = 5, защита от
   переполнения (насыщение в `[0,255]`);
5. медианный фильтр 3×3 — медиана по окну из 9 значений.

Раздел 1.7 (контуры):
- DoG — `|G3 − G5|` (`cv::absdiff`) × 7 (`cv::convertScaleAbs`, насыщение);
- Кэнни — `cv::Canny(src, 50, 200)` (готовая реализация OpenCV);
- индивидуальный вариант 1 — оператор Собела для горизонтальных контуров:
  `Gy = [[-1,-2,-1],[0,0,0],[1,2,1]]`, контур = `|a * Gy|`, насыщение в `[0,255]`.

В коде также реализованы все 10 операторов табл. 1.2 (переключение `--variant`).

## Изображения в отчёте

Изображения в `results/` — это прямой вывод скомпилированной C++-программы
(`./lab1 test_image.tiff results --variant 1`). Корректность проверена сверкой
с независимым Python-портом того же алгоритма (`gen_images.py`): все фильтры
совпадают с точностью до округления float (медиана, мозаика, апертурная,
Кэнни, вариант 1 — побайтово; Гаусс ±1 LSB; DoG ±7 — это ×7-усиление ±1 LSB).
`montage.png` — монтаж всех результатов с подписями для просмотра на экране.
